scratchpad-diagrams

Fleet optimisation before/after graphs, generated with archify (typed JSON IR, deterministic HTML/SVG). Marlin seat, 2026-09-17/18. Every number on the diagrams was measured, not estimated.

1. Marlin mesh watch chain 18.5M to 7M tokens per idle day; the stranded-dispatch miss eliminated

Before
Burst self-deleted on cold streak, 2h backstop
QUIET-STREAK counted only marlin-addressed mail; Antigravity's dispatch landed 10 minutes after the burst died and sat under a 2-hour backstop.
After
Warm-reset burst + hourly daytime backstop + REARM loop
Any fleet traffic under 45 min holds the burst; the backstop prompt carries the burst prompt verbatim so the pair self-heals after compaction; fail-loud seen-set.

2. Antigravity wake chain 288 LLM turns/day to ~0; mail wake under 1 second

Before
5-minute cron sink
A schedule cron forced a full LLM turn every 5 minutes, empty queue or not: ~23M tokens/day and 576 empty turns bloating the session context.
After
Reactive monitor + deterministic 30-min deadman
One background task; mail pokes the session in under a second; the deadman runs a --check that prints IDLE in under 50 ms without waking the model.

3. Gemma auditor card pipeline fleet backlog 5,031 to 2,124 cards; the 4,304-card single-key collision found and fixed

Before
Unbounded piles + one dummy hash + chain-merge blobs
1,680 active cards back to July; all 4,304 relation candidates collapsed into a single card_key, silently defeating every tombstone and dismissal downstream.
After
Compaction, real keys, star clustering, hardened ledger
Lane O 1,680 to 189; relations 4,304 to 1,397 verified; seed-exemplar clustering with proven 0.90 floor; four adversarial loops caught seven defects green suites missed.

4. Two-seat coordination serial ping-pong path to task DAG + wrap-up ledger; first cycle executed 2026-09-18

Before
Serial ping-pong path graph
Every exchange was a path: seat A posts, waits 2-5 minutes, seat B replies, waits. Wall time equalled chain depth, and every hop re-read full session context.
After
Task DAG with frontier dispatch + bounded wrap-up ledger
Their build unblocked my node and my completion unblocked theirs with zero ping-pong; resuming seats read the last 3-5 ledger entries instead of full history.

5. Auditor lane execution & hardening 8 vulnerabilities resolved, GPU leak eliminated, 22/22 unit tests green

Before
Bare subprocesses, TOCTOU locks, partial JSON crashes
Orphaned lane child burned 84% GPU for 70 minutes with zero watchdog supervision; check-then-act lock races allowed double-spawns; unhandled test runner crashes.
After
Supervised execution, atomic locks, safe I/O, hardened suites
Parent PID supervision + atomic lock reclamation prevents GPU leaks; partial-line trailing guards prevent JSON corruption; test suite restored to 100% green.
